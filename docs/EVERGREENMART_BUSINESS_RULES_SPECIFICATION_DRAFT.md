### 1.5. Quy ước phân loại mức độ triển khai
Mỗi quy tắc nghiệp vụ trong tài liệu được gắn duy nhất một trong sáu trạng thái sau:

| Trạng thái | Ý nghĩa |
|---|---|
| `IMPLEMENTED` | Đã triển khai đầy đủ logic thực tế đồng bộ từ giao diện đến API và cơ sở dữ liệu, có căn cứ rõ ràng trong source code. |
| `PARTIALLY IMPLEMENTED` | Đã có logic xử lý một phần nhưng thiếu điều kiện kiểm tra, thiếu nhánh ngoại lệ, hoặc bất nhất giữa Frontend và Backend. |
| `UI ONLY` | Mới chỉ có giao diện, nút bấm, bộ lọc hoặc văn bản hiển thị phía Frontend; chưa có API hoặc logic xử lý thực tế phía Backend. |
| `NOT IMPLEMENTED` | Chưa tìm thấy bất kỳ logic triển khai thực tế nào trong source code cho nghiệp vụ này. |
| `NEEDS CONFIRMATION` | Có dữ liệu, trường thông tin hoặc dấu hiệu liên quan trong code nhưng mâu thuẫn nhau hoặc chưa đủ căn cứ kết luận chính sách chuẩn. |
| `PROPOSED` | Quy định nghiệp vụ đã được xác định về mặt chủ trương (như phạm vi 4 danh mục hủy/đổi/trả) hoặc đề xuất kiểm soát cần triển khai vào hệ thống. |
